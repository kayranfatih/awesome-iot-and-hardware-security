# Contribution Guidelines

Please ensure your pull request adheres to the following guidelines:

- Search the list and previous pull requests before adding a resource, as yours may be a duplicate.
- Only suggest resources related to IoT, embedded, and hardware security that you think are genuinely useful.
- Prefer resources that are maintained. If a project is archived or no longer maintained, say so in its description.
- Make an individual pull request for each suggestion.
- Use the following format: `- [Resource Name](https://link) - Short description ending with a period.`
- Do not start the description with the resource name, and keep it neutral and concise rather than marketing copy.
- Books use the format `- [Title](https://link) - Year, Publisher: Name, Author(s): Names.` and are sorted by year, newest first.
- Add new items to the bottom of the relevant category.
- New categories or improvements to the existing categorization are welcome. Update the Contents section when you add a category.
- Check that every link works and points to the canonical page, not a redirect or a tracking URL.
- Check your spelling and grammar.
- Make sure your text editor is set to remove trailing whitespace.
- The pull request and commit should have a useful title.

Thank you for your suggestions!
